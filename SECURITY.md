# Security Policy

Please do not report security vulnerabilities in public issues.

For vulnerabilities involving authentication, token handling, request forwarding, or Cloudflare deployment configuration:

- use GitHub private vulnerability reporting for this repository if it is enabled
- otherwise, contact the maintainer through a private channel before sharing details publicly

When reporting a vulnerability, include:

- affected commit or branch
- reproduction steps
- impact
- any suggested mitigation

Do not include real Skylight tokens, bearer tokens, or production secrets in bug reports.
